# Rahul Bhatiya — D2C Growth Partner Landing Page (React + Vite + Tailwind CSS)

A high-converting, responsive landing page built with **React**, **Vite**, and **Tailwind CSS** for **Rahul Bhatiya — D2C Growth Partner**.

## Quick Start

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Customization Guide

- **Client Portrait:** Located at `public/rahul-bhatiya.png` (already cropped and color-balanced). Replace this file anytime to update both the Hero and About sections.
- **Copy & Proof Metrics:** Edit `src/data/landingData.js` to update campaign numbers, ROAS cards, pain points, or deliverables.
- **Campaign Video:** Update `src/components/VideoModal.jsx` with your YouTube, Vimeo, or Loom iframe embed.
- **Strategy Call Form:** Connect `handleSubmit` inside `src/components/StrategyModal.jsx` to your webhook, CRM, Calendly, or WhatsApp API.
